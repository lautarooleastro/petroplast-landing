## 🎨 Especificaciones Técnicas

### Formato y Calidad
- **Formato**: JPG (optimizado para web)
- **Calidad**: 85-90% de compresión
- **Peso máximo**: 500KB por imagen
- **Resolución**: 72 DPI

### Optimización
- Usar herramientas como TinyPNG o ImageOptim
- Generar versiones WebP para navegadores compatibles
- Crear versiones responsive (diferentes tamaños)
